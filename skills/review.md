交付前逐项确认：

**正确性**
· 边界：空输入、0、负数、超长、重复值
· 异常路径：文件不存在、网络失败、权限不足是否都有处理
· 有没有 off-by-one

**安全**
· 路径拼接是否可能被 `../` 穿越
· 用户输入是否直接进了 shell / SQL / eval
· 有没有硬编码密钥

**可维护**
· 函数是否只做一件事
· 命名是否表达了意图（不是 `data`、`tmp`、`res`）
· 有没有重复的魔法数字

**验证充分性**
· 有没有实际跑过，而不是"看起来对"
· 测试是否覆盖了失败路径，不只测 happy path

发现问题时：**先说问题，再给修改**，不要默默改掉。
